隐私政策

生效日期：2026 年 9 月 26 日　|　适用应用：小安翻译（Android，包名 com.jbk.xiaoants）

小安翻译在设备上识别语言和翻译文字，历史与收藏保存在本机。首次使用语言模型需要联网；Google ML Kit 也会收集设备、应用和使用情况等诊断数据。下文说明各类数据的去向和删除方式。

处理的数据第三方保存与删除安全与权限联系我们

1. 适用范围

本政策适用于“小安翻译”应用，由开发者贾保康提供。应用无需注册或登录，不建立用户账号。我们不会运营用于接收翻译原文、译文、历史记录或收藏的服务器，也不使用这些内容投放广告或出售用户数据。

2. 应用处理的数据

  • 翻译内容：你输入或粘贴的文字、自动识别或手动选择的语言、译文在设备端处理。Google ML Kit 的语言识别与翻译 API 在设备上运行，原文和译文不会因这些 API 而发送到 Google 服务器；应用本身也不将其上传到我们的服务器。
  • 本地记录与偏好：成功翻译后，应用把原文、译文、语言、时间、收藏状态与翻译引擎标记保存到设备上的本地数据库；主题、默认目标语言和界面语言偏好也保存在本机。搜索历史在本机完成。
  • 语言模型与网络：首次使用尚未安装的语言模型时，应用通过 Google ML Kit 下载模型；模型或 SDK 更新也可能访问 Google 服务。默认仅在 Wi-Fi 下下载；下载失败后，你可以明确选择使用移动数据。你也可以在应用内查看或删除已下载的语言模型。
  • 诊断与使用数据：Google ML Kit SDK 可能向 Google 发送设备型号、系统版本、可用加速器、应用包名与版本、安装标识符、性能指标、调用事件、错误码、输入与输出的长度、识别出的语言，以及配置的源语言和目标语言，用于诊断、统计、维护和改进 ML Kit。Google 表示这些数据通过 HTTPS 传输。具体范围取决于实际使用的 ML Kit 功能与 SDK 版本。

3. 第三方及主动分享

  • Google：我们集成 Google ML Kit 的语言识别、设备端翻译及模型管理能力。Google 处理上述模型请求和 SDK 诊断数据；翻译原文和译文由 ML Kit 在本机处理。详情见 ML Kit 条款与隐私说明、ML Kit 数据披露说明和 Google 隐私权政策。
  • 设备语音服务：你主动使用朗读时，文字交由设备已安装的语音引擎处理。该引擎可能由设备厂商或第三方提供；是否联网、如何处理朗读文字，取决于你设备上的语音引擎及其隐私政策。
  • 剪贴板与分享对象：你主动点击复制或分享后，相应文字进入系统剪贴板或系统分享面板；只有在你选择接收应用后，分享内容才交给该应用。接收应用按其自己的隐私政策处理内容。

除上述 SDK 行为和你主动使用的系统功能外，应用不主动向其他第三方发送翻译内容，也不接入广告 SDK 或独立的行为分析服务。如果你通过邮件联系我们，我们会收到你提供的邮箱地址和邮件内容，用于回复你的问题。

4. 保存、管理与删除

本地翻译记录、收藏和设置会保留在设备中，直到你删除或卸载应用。你可以在“历史”页面逐条删除记录，或在“设置”中清空全部翻译历史；清空历史也会删除收藏。离线语言包可在“设置 → 离线语言包”中删除。Android 版本已关闭应用系统备份。

卸载应用会由操作系统删除应用本地数据。我们没有应用账号或自有翻译数据服务器，因此无法远程查看或删除设备中的记录。Google、设备语音引擎及你选择的分享应用各自保存的数据，适用其各自的政策和删除方式。

5. 安全与权限

应用的历史记录保存在 Android 应用私有存储空间，访问受设备系统权限保护。ML Kit 的网络数据按 Google 的说明使用 HTTPS 传输。应用使用网络权限下载语言模型和访问其 SDK 服务；当前版本不申请麦克风、相机、位置、通讯录或设备文件的广泛访问权限。请勿在需要保密的翻译内容上使用不受信任的语音引擎或分享应用。

6. 儿童

小安翻译不专门面向儿童，不建立账号，也不提供定向广告。若你对儿童使用本应用时的数据处理有疑问，请通过下方方式联系。

7. 政策更新

当应用功能、SDK 或数据处理方式发生变化时，我们会更新本页面及生效日期。重大变化会在适用时通过应用内方式告知。

隐私问题、数据处理疑问或删除联系邮件的请求，请联系开发者贾保康：jiabaokangsy@gmail.com。
