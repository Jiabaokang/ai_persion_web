## 六、完成一项任务后的强制更新

每完成一个任务，执行者必须同时完成以下操作：

1. 在详细计划中将该任务全部步骤从 `- [ ]` 改为 `- [x]`。
2. 将本表对应状态改为 `✅ 完成`。
3. 填写实际 commit hash；如果用户没有授权提交，填写“未提交”并说明原因。
4. 使用绝对时间填写完成时间。
5. 在“验证证据/接力备注”中记录实际命令和结果，例如 `42 tests passed`、`pnpm build exit 0`。
6. 若中断，将状态改为 `🔄 进行中`、`⏸ 暂停` 或 `🚧 阻塞`，精确写明停在详细计划的哪一个步骤。
7. 再运行 `git status --short`，记录新文件和未提交变更，避免后续 Agent 误删用户内容。
